## 🧪 ფუნქციური მოდულების დეტალური მიმოხილვა

### 1. 🔢 ჟანგვის რიცხვების განსაზღვრის ტრენაჟორი (Oxidation State Trainer)
- **წესების ინტერაქტიული ბარათი:** თავისუფალი ელემენტი = 0; წყალბადი = +1; ჟანგბადი = -2; მუდმივი მეტალები (Li, Na, K = +1; Mg, Ca, Ba = +2; Al = +3; F = -1); ნეიტრალურობის პრინციპი (ჯამი = 0) და რთული იონის მუხტი.
- **ფორმულის ინტერაქტიული მკვლევარი:**
  - ნივთიერებები: `KMnO₄`, `K₂Cr₂O₇`, `H₂SO₄`, `HNO₃`, `NH₄NO₃` (განსაკუთრებული შემთხვევა: აზოტი ორ იონში -3 და +5), `H₂O₂` (პეროქსიდის გამონაკლისი -1), `NaH` (ჰიდრიდის გამონაკლისი -1), `SO₄²⁻` (რთული იონი).
  - ატომზე დაწკაპუნებით იხსნება ალგებრული განტოლება:
    $$\text{მაგ. } \text{KMnO}_4: \quad (+1) \cdot 1 + (x) \cdot 1 + (-2) \cdot 4 = 0 \implies x = +7$$
  - `+` / `&minus;` ღილაკებით ჟანგვის რიცხვის შერჩევა და მომენტალური ვალიდაცია.

### 2. 🔬 ვირტუალური ლაბორატორია (Redox Lab & Daniell Cell - HTML5 Canvas)
- **სიმულაცია 1: მეტალთა განდევნა (Zn + CuSO₄ &rarr; ZnSO₄ + Cu)**
  - *მაკროსკოპული ხედი:* ცისფერი CuSO₄ ხსნარი დროთა განმავლობაში უფერულდება, ხოლო თუთიის ვერცხლისფერ ფირფიტაზე ილექება მოწითალო-ყავისფერი სპილენძის ფოროვანი ფენა.
  - *მიკროსკოპული (ატომური) ხედი:* თუთიის კრისტალური მესერიდან Zn⁰ ატომი გასცემს 2e⁻-ს interface-ზე, გადაიქცევა Zn²⁺ იონად და გადადის ხსნარში. ხსნარში მოძრავი ცისფერი Cu²⁺ იონი იღებს ამ 2e⁻-ს და მეტალურ Cu⁰-ად ლექება ფირფიტაზე.
- **სიმულაცია 2: დანიელის გალვანური ელემენტი (Daniell Galvanic Cell)**
  - ანოდის ჭიქა (Zn | ZnSO₄) და კათოდის ჭიქა (Cu | CuSO₄).
  - U-ფორმის მარილოვანი ხიდაკი (KNO₃/KCl) ანიონებისა და კატიონების მიგრაციით მუხტის ნეიტრალიზაციისთვის.
  - გარე წრედი: ვოლტმეტრი (აჩვენებს 1.10 V), ჩამრთველი და მანათობელი ნათურა რეალისტური ჰალოთი.
  - მავთულში მოძრავი ელექტრონების ანიმაცია ანოდიდან კათოდისკენ:
    $$\text{ანოდი (-): } \text{Zn}^0 - 2e^- \to \text{Zn}^{2+} \quad (\text{ჟანგვა})$$
    $$\text{კათოდი (+): } \text{Cu}^{2+} + 2e^- \to \text{Cu}^0 \quad (\text{აღდგენა})$$

### 3. ⚖️ ელექტრონული ბალანსის სახელოსნო (Balance Workshop)
- 5 პროგრესული სირთულის რეაქცია:
  1. `Fe + Cl₂ → FeCl₃` (მარტივი ნივთიერებები)
  2. `Al + HCl → AlCl₃ + H₂` (მეტალი + მჟავა)
  3. `Cu + HNO₃(განზ.) → Cu(NO₃)₂ + NO + H₂O` (აზოტი ორ როლში)
  4. `KMnO₄ + HCl → KCl + MnCl₂ + Cl₂ + H₂O` (ქლორის ლაბორატორიული მიღება)
  5. `K₂Cr₂O₇ + FeSO₄ + H₂SO₄ → Cr₂(SO₄)₃ + Fe₂(SO₄)₃ + K₂SO₄ + H₂O` (დიქრომატი მჟავა არეში)
- 4-ნაბიჯიანი სკაფოლდინგი:
  - **ნაბიჯი 1:** მჟანგავისა და აღმდგენის ამოცნობა (მხარდაჭერილია როგორც ქიმიური სიმბოლოები, ისე ქართული სახელწოდებები: Fe/რკინა, Cl/ქლორი და ა.შ.).
  - **ნაბიჯი 2:** ელექტრონული ნახევარრეაქციები და გაცემული/შეძენილი ელექტრონების რაოდენობა.
  - **ნაბიჯი 3:** უმცირესი საერთო ჯერადის (უსჯ) და გამრავლების კოეფიციენტების პოვნა.
  - **ნაბიჯი 4:** კოეფიციენტების გადატანა მთავარ ტოლობაში და ატომური ბალანსის გადამოწმება.

### 4. 🧠 სიტუაციური ქეისები და ტესტი (Formative Assessment)
- 6 ცხოვრებისეული ქეისი ესგ სტანდარტების მიხედვით:
  1. რკინის ლურსმანი და ვერცხლის მონეტა CuSO₄-ში (ბექეტოვის მწკრივი).
  2. გემების კორპუსების პროტექტორული დაცვა თუთიის ფილებით.
  3. სმარტფონის ლითიუმ-იონური აკუმულატორი (Li-ის ჟანგვა განმუხტვისას).
  4. აზოტმჟავასა და სპილენძის თავისებურება (რატომ არ გამოიყოფა H₂).
  5. გაჭრილი ვაშლის გაყავისფრება და C ვიტამინი როგორც ანტიოქსიდანტი.
  6. უჯრედული სუნთქვა (C₆H₁₂O₆ + 6O₂ → 6CO₂ + 6H₂O) როგორც გლობალური ენერგეტიკული რედოქსი.
- ტესტის წარმატებით დასრულებისას მოსწავლე იღებს **"მიღწევის სერტიფიკატს"** (შესაძლებელია საკუთარი სახელის მითითება, ბეჭდვა ან PDF-ში შენახვა).

აპლიკაცია არის სრულად დამოუკიდებელი (Self-contained) და არ საჭიროებს Node.js-ის, Python-ის ან რაიმე სერვერული პაკეტის ინსტალაციას:
1. გახსენით პროექტის საქაღალდე.
2. ორჯერ დააწკაპუნეთ ფაილზე **`open_app.cmd`** (ან პირდაპირ გახსენით **`index.html`** ნებისმიერ ბრაუზერში: Google Chrome, Microsoft Edge, Mozilla Firefox, Safari).
3. აპლიკაცია მომენტალურად ჩაიტვირთება 100%-ით გამართული ქართული ტიპოგრაფიითა და ინტერაქციით.
